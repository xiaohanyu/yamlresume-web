[Jake's Resume](https://github.com/jakegut/resume) 是有史以来最受欢迎的 LaTeX 简历模板之一。它由 Jake Gutierrez 基于 [sb2nov's resume](https://github.com/sb2nov/resume) 创建，在 GitHub 上已收获超过 2,800 颗星，并凭借其简洁、单栏、对 ATS 友好的设计，成为各大简历社区的默认推荐。

YAMLResume 在 [v0.12](/zh-cn/blog/v0.12) 中将 Jake's Resume 收录为官方 LaTeX 模板。本文将展示 Jake's Resume 在 YAMLResume 上的效果，以及——更重要的——YAMLResume 相比原始模板带来了哪些改进。

## 原始的 Jake's Resume

原始模板就是一个单独的 `resume.tex` 文件。在写下任何内容之前，你要先翻阅大约 100 行的导言区：各种宏包、页边距 hack、章节格式，以及一族自定义宏，如 `\resumeSubheading`、`\resumeItem` 和 `\resumeProjectHeading`。

内容直接用 LaTeX 编写：

```latex
\section{Education}
  \resumeSubHeadingListStart
    \resumeSubheading
      {Southwestern University}{Georgetown, TX}
      {Bachelor of Arts in Computer Science, Minor in Business}{Aug. 2018 -- May 2021}
  \resumeSubHeadingListEnd
```

![原始的 Jake's Resume](/static/images/blog/jakes-resume/original-jakes-resume.png)

效果很漂亮，但编写体验是纯粹的 LaTeX：你要手动输入每一个日期区间，转义每一个特殊字符（`Texas A\&M University`），还要在 LaTeX 出了名的晦涩错误日志里调试花括号不匹配的问题。想换个字体？注释、反注释 `\usepackage` 行。想加一门语言？重写整个文件。

有兴趣的话，这里是完整的 218 行 `resume.tex` 源码：

## 我们保留了什么

我们刻意保留了让 Jake's Resume 之所以是 Jake's Resume 的设计基因。事实上，在将模板适配到 YAMLResume 的架构之后，原始导言区中只有两段代码存活了下来：

```latex
% Sections formatting
\titleformat{\section}{
  \vspace{-4pt}\scshape\raggedright\large
}{}{0em}{}[\color{black}\titlerule \vspace{-5pt}]

% Custom commands
\newcommand{\resumeSubheading}[4]{
  \begin{tabular*}{\textwidth}[t]{l@{\extracolsep{\fill}}r}
    \textbf{#1} & #2 \\
    \textit{#3} & \textit{#4} \\
  \end{tabular*}
}
```

- `\titleformat`——带横线的小型大写字母章节标题
- `\resumeSubheading`——两行的条目头部，日期右对齐，用于工作、教育、项目以及所有其他带日期的章节

再加上居中的头部、` $|$ ` 联系方式分隔符和紧凑的 `nosep` 列表，这些共同承载了模板的全部视觉标识。其余的一切——大约十几个宏包和一整页的宏——都被 YAMLResume 的共享渲染管线所取代。

## 我们改进的地方

保留外观是容易的部分。真正的价值在于 YAMLResume 在其周围增加的一切。

### 内容与表现终于分离

在原始模板中，你的简历*就是* LaTeX 代码。在 YAMLResume 中，你的简历是数据。切换模板只需改动一行：

```yml lineNumbers
layouts:
  - engine: latex
    template: jake                  # or moderncv-banking, moderncv-casual, ...
```

而且由于 `layouts` 是一个列表，一个 YAML 文件可以同时生成 Jake's Resume 的 PDF、可直接上线的 [HTML 页面](/zh-cn/docs/layouts/html)，以及用于纯文本申请表单的 [Markdown](/zh-cn/docs/layouts/markdown) 副本——只需一次 `yamlresume build`。

### 带 schema 校验的结构化数据

每个字段都定义在公开的 [JSON Schema](/zh-cn/docs/compiler/schema) 中。借助文件顶部的 `yaml-language-server` 指令，你的编辑器会在输入时提供自动补全、内联文档和校验。学位、语言流利度、技能等级和社交网络都是枚举——拼写错误在你编译之前就会被捕获，而不是在一份 40 行的 LaTeX 错误日志之后。

### 告别手动转义

原始模板迫使你写成 `Texas A\&M University`。在 YAMLResume 中，你写 `Texas A&M University` 即可——LaTeX 转义会在渲染时自动应用，处处一致。

### 结构化、本地化的日期

日期是数据（`startDate: Aug 2018`），而不是硬编码在宏里的字符串。YAMLResume 会在整个文档中统一格式化日期，空的 `endDate` 会渲染为 "Present"——并翻译成你简历的语言。

### 真正的国际化

原始模板与英语硬绑定。YAMLResume 支持 [12 种区域语言](/zh-cn/docs/locale)——英语、中文（简体、繁体香港、繁体台湾）、西班牙语、法语、挪威语、荷兰语、日语、德语、印尼语和巴西葡萄牙语。章节标题、学位、流利度和日期格式都会自动翻译，并为每种语言提供相应的 `babel` 配置，以及通过 `ctex` 和 Noto 字体实现规范的 CJK 排版。

### Markdown 摘要

每个 `summary` 字段都接受一个实用的 markdown 子集——**加粗**、*斜体*、列表和[链接](https://yamlresume.dev)——并会被转换为正确的 LaTeX。而在原始模板中，你得手动内联编写 `\textbf{}` 和 `itemize` 环境。

### 排版与布局控制

在原始模板中需要编辑导言区的内容，在这里只是一个配置项：

```yml lineNumbers
layouts:
  - engine: latex
    template: jake
    page:
      paperSize: a4            # a4 | letter
      showPageNumbers: true
      margins:
        top: 2.5cm
        bottom: 2.5cm
        left: 1.5cm
        right: 1.5cm
    typography:
      fontSize: 11pt           # 10pt | 11pt | 12pt
      lineSpacing: relaxed     # tight | snug | normal | relaxed | loose
      fontFamily: Linux Libertine O
    advanced:
      showIcons: true
      showUrls: true
```

页边距由 `geometry` 宏包处理，取代了原始的负边距 `\addtolength` hack；字体通过 `\IfFontExistsTF` 回退机制来解析，取代了注释/反注释的轮盘赌。

### 章节别名与重排序

无需触碰 LaTeX，即可重命名任何章节标题或调整章节顺序——例如，把 Projects 放在 Work 之前，或者把 "Work" 改名为 "Experience"：

```yml lineNumbers
layouts:
  - engine: latex
    template: jake
    sections:
      aliases:
        work: Experience
      order:
        - projects
        - work
```

详情请参阅[章节别名](/zh-cn/docs/layouts/sections/aliases)和[章节重排序](/zh-cn/docs/layouts/sections/reorder)。

### 现代化的链接、图标与 PDF 元数据

头部联系方式行带有可点击的 `tel:` 和 `mailto:` 链接、带隐藏链接边框的下划线 `\href`，以及可选的 FontAwesome 图标（自动从 `fontawesome7` 回退到 `fontawesome5`）。生成的 PDF 还带有规范的元数据——作者、标题，以及从你的技能中提取的关键词——而原始模板从未设置这些。

### 经过测试并持续维护

Jake 渲染器附带超过 700 行的单元测试，覆盖导言区、每个章节和每个布局选项，并且它建立在与我们 moderncv 模板相同的共享 `LatexRenderer` 基类之上——因此渲染管线的改进会自动惠及 Jake's Resume。

## 一览对比

|              | 原始 Jake's Resume | YAMLResume `template: jake` |
|--------------|--------------------|-----------------------------|
| 编写格式     | 原始 LaTeX         | 结构化 YAML                 |
| 校验         | LaTeX 编译错误     | JSON Schema + IDE 自动补全  |
| 特殊字符     | 手动转义           | 自动转义                    |
| 日期         | 手写的字符串       | 结构化、本地化              |
| 语言         | 仅英语             | 12 种区域语言，支持 CJK     |
| 富文本       | 内联 LaTeX 宏      | Markdown 摘要               |
| 模板         | 一个文件，一种设计 | 一行即可切换                |
| 输出格式     | 仅 PDF             | PDF、HTML、Markdown         |
| 布局定制     | 编辑导言区         | 配置项                      |
| 章节改名/重排 | 重写宏            | 配置项                      |
