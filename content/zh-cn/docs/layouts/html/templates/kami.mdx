## 实现

Kami（紙，"纸"）是一个温暖、受印刷品启发的 HTML 模板：羊皮纸背景、
单一的衬线字体，以及素雅的墨色点缀，整体排版如同一份精心排版的报
告。它非常适合希望网页呈现经典、文艺风格的求职者。

在底层，该模板使用：

- **暖色调色板**：羊皮纸背景，搭配墨色点缀用于标题、章节标题、链
  接和技能标签
- **单一衬线字体**：基于 Charter 的衬线字体栈让整个页面保持统一的
  字体家族，日期和分类使用小型大写字母标签
- **强调色支持**：全页面遵循 `theme.colors.accent`
- **响应式设计**：从桌面到移动屏幕都能清晰自适应
- **语义化 HTML**：规范的 HTML5 结构，提升可访问性和 SEO

## 配置

```yml lineNumbers title="resume.yml"
content:
  # ...

layouts:
  - engine: html
    template: kami    # [!code highlight]
    typography:
      fontSize: 16px
```

## 特性

- **受印刷品启发的设计**：无论是在屏幕上还是纸上，都看起来像一份精
  心排版的文档
- **可自定义强调色**：通过 `theme.colors.accent` 为标题、章节标题、
  链接和技能标签着色
- **网络就绪**：可以直接嵌入网站或通过 URL 分享
- **适合打印**：针对从网页浏览器打印为 PDF 优化
- **可自定义章节**：灵活的章节顺序和命名
