## Implémentation

Kami (紙, « papier ») est un modèle HTML chaleureux inspiré de l'impression :
un fond parchemin, une voix serif unique et des accents discrets de couleur
encre, composés comme un rapport soigneusement mis en page. Il convient
particulièrement aux candidats qui souhaitent une touche classique et
littéraire pour leur page web.

Sous le capot, le modèle utilise :

- **Palette Chaleureuse** : Un fond parchemin avec des accents de couleur encre
  pour les titres, les titres de section, les liens et les étiquettes de
  compétences
- **Voix Serif Unique** : Une pile serif basée sur Charter maintient la page
  entière dans une même famille typographique, avec des étiquettes en petites
  capitales pour les dates et les catégories
- **Prise en Charge de la Couleur d'Accent** : Respecte `theme.colors.accent`
  dans toute la page
- **Design Responsive** : S'adapte proprement des écrans de bureau aux écrans
  mobiles
- **HTML Sémantique** : Structure HTML5 appropriée pour une meilleure
  accessibilité et SEO

## Configuration

```yml lineNumbers title="resume.yml"
content:
  # ...

layouts:
  - engine: html
    template: kami    # [!code highlight]
    typography:
      fontSize: 16px
```

## Fonctionnalités

- **Design Inspiré de l'Impression** : Ressemble à un document soigneusement
  mis en page, à l'écran comme sur papier
- **Couleur d'Accent Personnalisable** : Teinte les titres, les titres de
  section, les liens et les étiquettes de compétences via `theme.colors.accent`
- **Prêt pour le Web** : Peut être intégré directement dans des sites web ou
  partagé via URL
- **Adapté à l'Impression** : Optimisé pour l'impression en PDF depuis les
  navigateurs web
- **Sections Personnalisables** : Ordre et dénomination flexibles des sections

## Aperçu

Le modèle Kami offre une apparence calme et studieuse qui laisse votre contenu
se lire comme un document professionnellement mis en page.
