[Jake's Resume](https://github.com/jakegut/resume) est l'un des modèles de CV
LaTeX les plus populaires jamais créés. Conçu par Jake Gutierrez à partir du
[CV de sb2nov](https://github.com/sb2nov/resume), il a récolté plus de 2 800
étoiles sur GitHub et est devenu une recommandation par défaut dans les
communautés de CV grâce à son design épuré, en une seule colonne et compatible
ATS.

YAMLResume a adopté Jake's Resume comme modèle LaTeX officiel dans la
[v0.12](/fr/blog/v0.12). Dans cet article, nous vous montrerons à quoi
ressemble Jake's Resume sur YAMLResume et — surtout — ce que YAMLResume
améliore par rapport au modèle original.

## Le Jake's Resume original

Le modèle original est un seul fichier `resume.tex`. Avant d'écrire le moindre
mot de contenu, vous devez traverser environ 100 lignes de préambule :
packages, bidouilles de marges, formatage des sections et une famille de
macros personnalisées comme `\resumeSubheading`, `\resumeItem` et
`\resumeProjectHeading`.

Le contenu est ensuite écrit directement en LaTeX :

```latex
\section{Education}
  \resumeSubHeadingListStart
    \resumeSubheading
      {Southwestern University}{Georgetown, TX}
      {Bachelor of Arts in Computer Science, Minor in Business}{Aug. 2018 -- May 2021}
  \resumeSubHeadingListEnd
```

![Le Jake's Resume original](/static/images/blog/jakes-resume/original-jakes-resume.png)

Le résultat est superbe, mais l'expérience de rédaction est du pur LaTeX :
vous tapez à la main chaque plage de dates, vous échappez chaque caractère
spécial (`Texas A\&M University`) et vous déboguez les accolades mal
assorties à travers les journaux d'erreurs de LaTeX, célèbres pour leur
opacité. Vous voulez une autre police ? Commentez et décommentez des lignes
`\usepackage`. Vous voulez une deuxième langue ? Réécrivez le fichier.

Pour les curieux, voici la source complète de `resume.tex` en 218 lignes :

## Ce que nous avons conservé

Nous avons délibérément préservé l'ADN du design qui fait de Jake's Resume
Jake's Resume. En fait, après l'adaptation du modèle à l'architecture de
YAMLResume, seuls deux éléments du préambule original ont survécu :

```latex
% Sections formatting
\titleformat{\section}{
  \vspace{-4pt}\scshape\raggedright\large
}{}{0em}{}[\color{black}\titlerule \vspace{-5pt}]

% Custom commands
\newcommand{\resumeSubheading}[4]{
  \begin{tabular*}{\textwidth}[t]{l@{\extracolsep{\fill}}r}
    \textbf{#1} & #2 \\
    \textit{#3} & \textit{#4} \\
  \end{tabular*}
}
```

- `\titleformat` — le titre de section en petites capitales avec un filet
  horizontal
- `\resumeSubheading` — l'en-tête d'entrée sur deux lignes avec les dates
  alignées à droite, utilisé pour l'expérience, la formation, les projets et
  toutes les autres sections datées

Avec l'en-tête centré, le séparateur de contact ` $|$ ` et les listes
`itemize` compactes `nosep`, ces éléments portent à eux seuls toute
l'identité visuelle du modèle. Tout le reste — une douzaine de packages et
une page de macros — a été remplacé par le pipeline de rendu partagé de
YAMLResume.

## Ce que nous avons amélioré

Conserver le style était la partie facile. La vraie valeur réside dans tout
ce que YAMLResume ajoute autour.

### Le contenu, enfin séparé de la présentation

Dans le modèle original, votre CV *est* du code LaTeX. Dans YAMLResume,
votre CV est une donnée. Changer de modèle tient en une ligne :

```yml lineNumbers
layouts:
  - engine: latex
    template: jake                  # or moderncv-banking, moderncv-casual, ...
```

Et comme `layouts` est une liste, un seul fichier YAML peut produire un PDF
Jake's Resume, une [page HTML](/fr/docs/layouts/html) prête pour le web et
une version [Markdown](/fr/docs/layouts/markdown) pour les formulaires de
candidature en texte brut — le tout en une seule commande `yamlresume
build`.

### Des données structurées avec validation par schéma

Chaque champ est défini dans un [schéma JSON](/fr/docs/compiler/schema)
public. Grâce à la directive `yaml-language-server` en tête de fichier,
votre éditeur fournit l'autocomplétion, la documentation en ligne et la
validation au fil de la saisie. Les diplômes, niveaux de langue, niveaux de
compétence et réseaux de profils sont des énumérations — les fautes de
frappe sont détectées avant même la compilation, et non après un journal
d'erreurs LaTeX de 40 lignes.

### Fini l'échappement manuel

Le modèle original vous oblige à écrire `Texas A\&M University`. Dans
YAMLResume, vous écrivez `Texas A&M University` — l'échappement LaTeX est
appliqué automatiquement au moment du rendu, partout et de manière
cohérente.

### Des dates structurées et localisées

Les dates sont des données (`startDate: Aug 2018`), pas des chaînes figées
dans des macros. YAMLResume les formate de manière cohérente dans tout le
document, et un `endDate` vide s'affiche comme « Present » — traduit dans la
langue de votre CV.

### Une vraie internationalisation

Le modèle original est figé en anglais. YAMLResume prend en charge [12
langues régionales](/fr/docs/locale) — anglais, chinois (simplifié,
traditionnel HK, traditionnel TW), espagnol, français, norvégien,
néerlandais, japonais, allemand, indonésien et portugais brésilien. Les
titres de section, diplômes, niveaux de langue et formats de date sont
traduits automatiquement, avec une configuration `babel` par langue et une
composition CJK correcte via `ctex` et les polices Noto.

### Des résumés en markdown

Chaque champ `summary` accepte un sous-ensemble pratique de markdown —
**gras**, *italique*, listes et [liens](https://yamlresume.dev) — qui est
converti en LaTeX correct. Dans le modèle original, vous écrivez à la main
`\textbf{}` et des environnements `itemize` en ligne.

### Contrôles de typographie et de mise en page

Ce qui exigeait de modifier le préambule dans l'original devient ici une
option de configuration :

```yml lineNumbers
layouts:
  - engine: latex
    template: jake
    page:
      paperSize: a4            # a4 | letter
      showPageNumbers: true
      margins:
        top: 2.5cm
        bottom: 2.5cm
        left: 1.5cm
        right: 1.5cm
    typography:
      fontSize: 11pt           # 10pt | 11pt | 12pt
      lineSpacing: relaxed     # tight | snug | normal | relaxed | loose
      fontFamily: Linux Libertine O
    advanced:
      showIcons: true
      showUrls: true
```

Les marges sont gérées par le package `geometry` au lieu des bidouilles de
marges négatives `\addtolength` de l'original, et les polices sont résolues
avec des solutions de repli `\IfFontExistsTF` au lieu de la roulette du
commenter/décommenter.

### Alias et réordonnancement des sections

Renommez n'importe quel titre de section ou changez l'ordre des sections
sans toucher au LaTeX — par exemple, placez les projets avant l'expérience,
ou renommez « Work » en « Experience » :

```yml lineNumbers
layouts:
  - engine: latex
    template: jake
    sections:
      aliases:
        work: Experience
      order:
        - projects
        - work
```

Voir les [alias de section](/fr/docs/layouts/sections/aliases) et le
[réordonnancement des sections](/fr/docs/layouts/sections/reorder) pour plus
de détails.

### Liens modernes, icônes et métadonnées PDF

La ligne de contact de l'en-tête obtient des liens cliquables `tel:` et
`mailto:`, des `\href` soulignés sans bordures de lien, et des icônes
FontAwesome optionnelles (avec un repli automatique de `fontawesome7` vers
`fontawesome5`). Le PDF généré emporte également des métadonnées correctes —
auteur, titre et mots-clés dérivés de vos compétences — que le modèle
original ne renseigne jamais.

### Testé et maintenu

Le moteur de rendu Jake est livré avec plus de 700 lignes de tests unitaires
couvrant le préambule, chaque section et chaque option de mise en page, et
il repose sur la même base partagée `LatexRenderer` que nos modèles moderncv
— les améliorations du pipeline profitent donc automatiquement à Jake's
Resume.

## En bref

|                              | Jake's Resume original    | YAMLResume `template: jake`       |
|------------------------------|---------------------------|-----------------------------------|
| Format de rédaction          | LaTeX brut                | YAML structuré                    |
| Validation                   | Erreurs de compilation LaTeX | Schéma JSON + complétion IDE   |
| Caractères spéciaux          | Échappement manuel        | Automatique                       |
| Dates                        | Chaînes tapées à la main  | Structurées, localisées           |
| Langues                      | Anglais uniquement        | 12 langues régionales, prêt pour CJK |
| Texte enrichi                | Macros LaTeX en ligne     | Résumés en markdown               |
| Modèles                      | Un fichier, un design     | Une ligne pour changer            |
| Formats de sortie            | PDF uniquement            | PDF, HTML, Markdown               |
| Personnalisation de la mise en page | Modifier le préambule | Options de configuration          |
| Renommage/réordonnancement des sections | Réécrire les macros | Options de configuration   |

## Essayez dès aujourd'hui

```console
$ npm install -g yamlresume
$ yamlresume new resume.yml
# edit resume.yml, set `template: jake`
$ yamlresume build resume.yml
```

Ou ouvrez le [playground](/fr/playground) et basculez le modèle sur `jake`
pour le voir en direct dans votre navigateur.
