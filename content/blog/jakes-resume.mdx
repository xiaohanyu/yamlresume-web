[Jake's Resume](https://github.com/jakegut/resume) is one of the most popular
LaTeX resume templates ever made. Created by Jake Gutierrez on top of
[sb2nov's resume](https://github.com/sb2nov/resume), it has earned over 2,800
stars on GitHub and become a default recommendation in resume communities for
its clean, single-column, ATS-friendly design.

YAMLResume adopted Jake's Resume as an official LaTeX template in
[v0.12](/blog/v0.12). In this post we will show you what Jake's Resume looks
like on YAMLResume, and — more importantly — what YAMLResume improves over the
original template.

## The Original Jake's Resume

The original template is a single `resume.tex` file. Before you write a single
word of content, you wade through about 100 lines of preamble: packages,
margin hacks, section formatting, and a family of custom macros like
`\resumeSubheading`, `\resumeItem`, and `\resumeProjectHeading`.

Content is then written directly in LaTeX:

```latex
\section{Education}
  \resumeSubHeadingListStart
    \resumeSubheading
      {Southwestern University}{Georgetown, TX}
      {Bachelor of Arts in Computer Science, Minor in Business}{Aug. 2018 -- May 2021}
  \resumeSubHeadingListEnd
```

![The original Jake's Resume](/static/images/blog/jakes-resume/original-jakes-resume.png)

The result is beautiful, but the authoring experience is pure LaTeX: you
hand-type every date range, escape every special character (`Texas A\&M
University`), and debug brace mismatches through LaTeX's famously cryptic
error logs. Want a different font? Comment and uncomment `\usepackage` lines.
Want a second language? Rewrite the file.

## What We Kept

We deliberately preserved the design DNA that makes Jake's Resume Jake's
Resume. In fact, after adapting the template to YAMLResume's architecture,
only two pieces of the original preamble survived:

```latex
% Sections formatting
\titleformat{\section}{
  \vspace{-4pt}\scshape\raggedright\large
}{}{0em}{}[\color{black}\titlerule \vspace{-5pt}]

% Custom commands
\newcommand{\resumeSubheading}[4]{
  \begin{tabular*}{\textwidth}[t]{l@{\extracolsep{\fill}}r}
    \textbf{#1} & #2 \\
    \textit{#3} & \textit{#4} \\
  \end{tabular*}
}
```

- `\titleformat` — the small-caps section heading with a horizontal rule
- `\resumeSubheading` — the two-row entry header with right-aligned dates,
  used for work, education, projects, and all other dated sections

Together with the centered header, the ` $|$ ` contact separator, and the
compact `nosep` itemize lists, these carry the entire visual identity of the
template. Everything else — about a dozen packages and a page of macros — was
replaced by YAMLResume's shared rendering pipeline.

## What We Improved

Keeping the look was the easy part. The real value is everything YAMLResume
adds around it.

### Content, finally separated from presentation

In the original template, your resume *is* LaTeX code. In YAMLResume, your
resume is data. Switching templates is a one-line change:

```yml lineNumbers
layouts:
  - engine: latex
    template: jake                  # or moderncv-banking, moderncv-casual, ...
```

And because `layouts` is a list, one YAML file can produce a Jake's Resume
PDF, a web-ready [HTML page](/docs/layouts/html), and a
[Markdown](/docs/layouts/markdown) copy for plain-text application forms — all
in a single `yamlresume build`.

### Structured data with schema validation

Every field is defined in a public [JSON
Schema](/docs/compiler/schema). With the `yaml-language-server` directive at
the top of your file, your editor provides autocompletion, inline
documentation, and validation as you type. Degrees, language fluencies, skill
levels, and profile networks are enums — typos are caught before you ever
compile, not after a 40-line LaTeX error log.

### No more manual escaping

The original template forces you to write `Texas A\&M University`. In
YAMLResume you write `Texas A&M University` — LaTeX escaping is applied
automatically at render time, everywhere, consistently.

### Structured, localized dates

Dates are data (`startDate: Aug 2018`), not strings baked into macros.
YAMLResume formats them consistently across the whole document, and an empty
`endDate` renders as "Present" — translated into your resume's language.

### Real internationalization

The original template is hardwired to English. YAMLResume supports [12 locale
languages](/docs/locale) — English, Chinese (Simplified, Traditional HK,
Traditional TW), Spanish, French, Norwegian, Dutch, Japanese, German,
Indonesian, and Brazilian Portuguese. Section titles, degrees, fluency levels,
and date formats are translated automatically, with per-language `babel`
setup and proper CJK typesetting via `ctex` and Noto fonts.

### Markdown summaries

Every `summary` field accepts a practical subset of markdown — **bold**,
*italic*, lists, and [links](https://yamlresume.dev) — which is converted to
correct LaTeX. In the original template you hand-write `\textbf{}` and
`itemize` environments inline.

### Typography and layout controls

What requires editing the preamble in the original is a config option here:

```yml lineNumbers
layouts:
  - engine: latex
    template: jake
    page:
      paperSize: a4            # a4 | letter
      showPageNumbers: true
      margins:
        top: 2.5cm
        bottom: 2.5cm
        left: 1.5cm
        right: 1.5cm
    typography:
      fontSize: 11pt           # 10pt | 11pt | 12pt
      lineSpacing: relaxed     # tight | snug | normal | relaxed | loose
      fontFamily: Linux Libertine O
    advanced:
      showIcons: true
      showUrls: true
```

Margins are handled by the `geometry` package instead of the original's
negative-margin `\addtolength` hacks, and fonts are resolved with
`\IfFontExistsTF` fallbacks instead of comment/uncomment roulette.

### Section aliases and reordering

Rename any section title or change the section order without touching LaTeX —
for example, put Projects before Work, or rename "Work" to "Experience":

```yml lineNumbers
layouts:
  - engine: latex
    template: jake
    sections:
      aliases:
        work: Experience
      order:
        - projects
        - work
```

See [section aliases](/docs/layouts/sections/aliases) and [section
reorder](/docs/layouts/sections/reorder) for details.

### Modern links, icons, and PDF metadata

The header contact line gets clickable `tel:` and `mailto:` links, underlined
`\href`s with hidden link borders, and optional FontAwesome icons (with an
automatic `fontawesome7` → `fontawesome5` fallback). The generated PDF also
carries proper metadata — author, title, and keywords derived from your
skills — which the original template never sets.

### Tested and maintained

The Jake renderer ships with over 700 lines of unit tests covering the
preamble, every section, and every layout option, and it is built on the same
shared `LatexRenderer` base as our moderncv templates — so improvements to
the pipeline land on Jake's Resume automatically.

| Authoring format       | Raw LaTeX              | Structured YAML                |
| Validation             | LaTeX compile errors   | JSON Schema + IDE completion   |
| Special characters     | Manual escaping        | Automatic                      |
| Dates                  | Hand-typed strings     | Structured, localized          |
| Languages              | English only           | 12 locale languages, CJK ready |
| Rich text              | Inline LaTeX macros    | Markdown summaries             |
| Templates              | One file, one design   | One line to switch             |
| Output formats         | PDF only               | PDF, HTML, Markdown            |
| Layout customization   | Edit the preamble      | Config options                 |
| Section rename/reorder | Rewrite macros         | Config options                 |

## Try It Today

```console
$ npm install -g yamlresume
$ yamlresume new resume.yml
# edit resume.yml, set `template: jake`
$ yamlresume build resume.yml
```

Or open the [playground](/playground) and switch the template to `jake` to see
it live in your browser.
