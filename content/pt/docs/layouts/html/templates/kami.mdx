## Implementação

Kami (紙, "papel") é um modelo HTML quente e inspirado na impressão: um fundo
de pergaminho, uma única voz serifada e acentos discretos na cor de tinta,
composto como um relatório com boa composição tipográfica. É uma boa opção
para candidatos que procuram um toque clássico e literário numa página web.

Internamente, o modelo utiliza:

- **Paleta Quente**: Um fundo de pergaminho com acentos na cor de tinta para
  títulos, títulos de secções, hiperligações e etiquetas de competências
- **Única Voz Serifada**: Uma pilha serifada baseada em Charter mantém toda a
  página numa única família tipográfica, com etiquetas em versalete para
  datas e categorias
- **Suporte de Cor de Destaque**: Respeita `theme.colors.accent` em toda a
  página
- **Design Responsivo**: Adapta-se bem de desktops a ecrãs móveis
- **HTML Semântico**: Estrutura HTML5 adequada para melhor acessibilidade e
  SEO

## Configuração

```yml lineNumbers title="resume.yml"
content:
  # ...

layouts:
  - engine: html
    template: kami    # [!code highlight]
    typography:
      fontSize: 16px
```

## Características

- **Design Inspirado na Impressão**: Parece um documento cuidadosamente
  composto tipograficamente, tanto no ecrã como no papel
- **Cor de Destaque Personalizável**: Colore títulos, títulos de secções,
  hiperligações e etiquetas de competências através de `theme.colors.accent`
- **Pronto para Web**: Pode ser incorporado diretamente em sites ou
  partilhado através de URL
- **Apropriado para Impressão**: Otimizado para imprimir em PDF a partir de
  navegadores web
- **Secções Personalizáveis**: Ordenação e nomenclatura flexível de secções
