title: Motor LaTeX
---

O motor LaTeX é o motor central do YAMLResume, concebido para produzir currículos em PDF de alta qualidade e aspeto profissional utilizando modelos LaTeX.

## Configuração

Para utilizar o motor LaTeX, especifique `engine: latex` na sua configuração de layout.

```yaml
layouts:
  - engine: latex
    template: moderncv-banking
    # ... outras opções
```

## Página

A opção `page` permite personalizar a configuração da página, como o
tamanho do papel, as margens e se mostrar os números de página.

```yml lineNumbers
layouts:
  - engine: latex
    page:
      showPageNumbers: true
      # a4 ou letter
      paperSize: a4
      margins:
        top: 2.5cm
        left: 1.5cm
        right: 1.5cm
        bottom: 2.5cm
```

## Secções

A opção `sections` permite personalizar os títulos das secções e a sua ordem. Para mais informações, consulte a [documentação de secções](./sections).

```yml lineNumbers
layouts:
  - engine: latex
    sections:
      aliases:
        work: "Experiência Profissional"
        education: "Educação"
        skills: "Competências"
      order:
        - basics
        - work
        - education
```

## Modelos

A opção `template` permite escolher entre uma variedade de modelos. Cada modelo tem um design e disposição únicos. Pode encontrar uma lista de modelos disponíveis na [documentação de modelos](./latex/templates).

```yml lineNumbers
layouts:
  - engine: latex
    template: moderncv-banking
```

## Tipografia

A opção `typography` permite personalizar os estilos de fonte utilizados no seu currículo.

### Tamanho da fonte

A opção `fontSize` permite definir o tamanho de fonte base para o documento.
O motor LaTeX apenas suporta `10pt`, `11pt` e `12pt`.

### Família de fontes

A opção `fontFamily` permite especificar uma lista priorizada de nomes de famílias
de fontes. Isto funciona de forma semelhante à propriedade CSS `font-family`.

### Espaçamento de linha

A opção `lineSpacing` permite ajustar o espaçamento de linha do documento.
YAMLResume utiliza valores semânticos que são mapeados para o comando `\setstretch{}` do LaTeX:

| Valor    | Descrição                                    |
| -------- | -------------------------------------------- |
| `tight`  | Espaçamento compacto para caber mais conteúdo |
| `snug`   | Um pouco mais de espaço do que tight        |
| `normal` | Legibilidade equilibrada (predefinição)     |
| `relaxed`| Mais espaço entre linhas                   |
| `loose`  | Layout muito espaçado                      |

```yaml
layouts:
  - engine: latex
    typography:
      fontSize: 11pt
      fontFamily: "Merriweather, serif"
      lineSpacing: relaxed
```

## Tema

A opção `theme` permite personalizar a aparência visual do seu currículo sem
afetar a geometria de layout mensurável (tamanho da página, margens, tamanhos
de fonte) ou a estrutura de secções. Atualmente, suporta cores de destaque. O
motor markdown ignora a opção de tema.

```yml lineNumbers
layouts:
  - engine: latex
    theme:
      colors:
        accent: burgundy # ou uma cor hexadecimal arbitrária como "#1B365D"
```

Para saída LaTeX, os modelos moderncv mapeiam a cor de destaque para o
`color1` do moderncv, enquanto o modelo jake define um `accentcolor`
personalizado para títulos de secções e réguas. Quando nenhuma cor de
destaque está definida, cada modelo mantém a sua paleta predefinida.

## Avançado

A opção `advanced` permite configurar definições avançadas para o motor
LaTeX.

```yml lineNumbers
layouts:
  - engine: latex
    advanced:
      showIcons: true
      fontspec:
        numbers: Lining
```
