## 實現

Kami（紙，「紙張」之意）是一個溫暖、靈感來自印刷品的 HTML 模板：羊皮紙背景、
單一襯線字體，以及沉靜的墨色點綴，構圖如同一份排版精良的報告。它非常適合
希望網頁履歷呈現經典、文學氣息的求職者。

在底層，該模板使用：

- **暖色調色盤**：羊皮紙背景搭配墨色點綴，用於標題、章節標題、連結和技能標籤
- **單一襯線字體**：以 Charter 為基礎的襯線字體堆疊讓整頁保持統一的字體家族，
  日期與分類標籤採用小型大寫字
- **強調色支援**：全頁遵循 `theme.colors.accent`
- **響應式設計**：從桌面到移動裝置螢幕都能俐落適應
- **語義化 HTML**：適當的 HTML5 結構，提升可訪問性與 SEO

```yml lineNumbers title="resume.yml"

```

## 特性

- **靈感來自印刷品的設計**：無論在螢幕上或紙張上，都像一份精心排版的文件
- **可自定義的強調色**：透過 `theme.colors.accent` 為標題、章節標題、
  連結和技能標籤著色
- **網路就緒**：可直接嵌入網站或透過 URL 分享
- **適合列印**：針對從網頁瀏覽器列印為 PDF 最佳化
- **可自定義章節**：彈性的章節順序與命名
