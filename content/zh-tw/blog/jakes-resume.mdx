[Jake's Resume](https://github.com/jakegut/resume) 是有史以來最受歡迎的 LaTeX 履歷模板之一。它由 Jake Gutierrez 在 [sb2nov 的履歷模板](https://github.com/sb2nov/resume) 基礎上建立，已在 GitHub 上獲得超過 2,800 顆星星，並因其簡潔、單欄、ATS 友善的設計，成為履歷社群中的預設推薦。

YAMLResume 在 [v0.12](/zh-tw/blog/v0.12) 中將 Jake's Resume 收錄為官方 LaTeX 模板。在本文中，我們將展示 Jake's Resume 在 YAMLResume 上的樣貌，以及——更重要的是——YAMLResume 在原始模板之上做了哪些改進。

## 原版 Jake's Resume

原始模板是一個單獨的 `resume.tex` 檔案。在你寫下任何內容之前，你得先穿越約 100 行的前言（preamble）：套件載入、邊界調整技巧、章節格式設定，以及 `\resumeSubheading`、`\resumeItem` 和 `\resumeProjectHeading` 等一整套自訂巨集。

接著，內容直接以 LaTeX 撰寫：

```latex
\section{Education}
  \resumeSubHeadingListStart
    \resumeSubheading
      {Southwestern University}{Georgetown, TX}
      {Bachelor of Arts in Computer Science, Minor in Business}{Aug. 2018 -- May 2021}
  \resumeSubHeadingListEnd
```

![原版 Jake's Resume](/static/images/blog/jakes-resume/original-jakes-resume.png)

成果很美，但撰寫體驗是純粹的 LaTeX：每個日期區間都要手工輸入、每個特殊字元都要跳脫（`Texas A\&M University`）、還要透過 LaTeX 出了名的隱晦錯誤日誌來除錯大括號不匹配。想換字型？註解和取消註解 `\usepackage` 行。想要第二種語言？重寫整個檔案。

供好奇的讀者參考，以下是完整的 218 行 `resume.tex` 原始碼：

## 我們保留了什麼

我們刻意保留了讓 Jake's Resume 之所以是 Jake's Resume 的設計 DNA。事實上，在將模板適配到 YAMLResume 的架構之後，原始前言中只有兩個部分倖存下來：

```latex
% Sections formatting
\titleformat{\section}{
  \vspace{-4pt}\scshape\raggedright\large
}{}{0em}{}[\color{black}\titlerule \vspace{-5pt}]

% Custom commands
\newcommand{\resumeSubheading}[4]{
  \begin{tabular*}{\textwidth}[t]{l@{\extracolsep{\fill}}r}
    \textbf{#1} & #2 \\
    \textit{#3} & \textit{#4} \\
  \end{tabular*}
}
```

- `\titleformat` —— 帶橫線的小型大寫字母（small caps）章節標題
- `\resumeSubheading` —— 雙行條目標頭、日期靠右對齊，用於工作經歷、學歷、專案及所有其他附日期的章節

再加上置中的頁首、` $|$ ` 聯絡資訊分隔符，以及緊湊的 `nosep` 項目清單，這些承載了模板的整體視覺識別。其餘的一切——大約一打的套件和整整一頁的巨集——都被 YAMLResume 的共享渲染管線取代了。

## 我們改進了什麼

保留外觀是簡單的部分。真正的價值在於 YAMLResume 在其周圍加入的一切。

### 內容，終於與呈現分離

在原始模板中，你的履歷*就是* LaTeX 程式碼。在 YAMLResume 中，你的履歷是資料。切換模板只是一行的變動：

```yml lineNumbers
layouts:
  - engine: latex
    template: jake                  # or moderncv-banking, moderncv-casual, ...
```

而且因為 `layouts` 是一個清單，一個 YAML 檔案就能產生 Jake's Resume 的 PDF、可直接上網的 [HTML 頁面](/zh-tw/docs/layouts/html)，以及一份給純文字申請表單使用的 [Markdown](/zh-tw/docs/layouts/markdown) 副本——全部在一次 `yamlresume build` 中完成。

### 結構化資料與 schema 驗證

每個欄位都定義在公開的 [JSON Schema](/zh-tw/docs/compiler/schema) 中。只要在檔案頂部加上 `yaml-language-server` 指令，你的編輯器就會在你輸入時提供自動補全、內嵌文件說明和驗證。學位、語言流暢度、技能等級和個人檔案網站都是列舉值——錯字在你編譯之前就會被抓出來，而不是在一份 40 行的 LaTeX 錯誤日誌之後才發現。

### 不再需要手動跳脫

原始模板強迫你寫 `Texas A\&M University`。在 YAMLResume 中你寫 `Texas A&M University` 即可——LaTeX 跳脫會在渲染時自動、一致地套用到所有地方。

### 結構化、在地化的日期

日期是資料（`startDate: Aug 2018`），而不是寫死在巨集裡的字串。YAMLResume 會在整份文件中以一致的方式格式化日期，空白的 `endDate` 會渲染為「Present」——並翻譯成你履歷的語言。

### 真正的國際化

原始模板被寫死為英文。YAMLResume 支援 [12 種區域語言](/zh-tw/docs/locale)——英語、中文（簡體、繁體香港、繁體台灣）、西班牙語、法語、挪威語、荷蘭語、日語、德語、印尼語和巴西葡萄牙語。章節標題、學位、流暢度等級和日期格式都會自動翻譯，並針對每種語言設定 `babel`，透過 `ctex` 和 Noto 字型提供完善的 CJK 排版。

### Markdown 摘要

每個 `summary` 欄位都接受實用的 markdown 子集——**粗體**、*斜體*、清單和[連結](https://yamlresume.dev)——並會被轉換成正確的 LaTeX。在原始模板中，你得手寫 `\textbf{}` 和 `itemize` 環境。

### 排版與版面控制

在原始模板中需要編輯前言才能做的事，在這裡只是一個設定選項：

```yml lineNumbers
layouts:
  - engine: latex
    template: jake
    page:
      paperSize: a4            # a4 | letter
      showPageNumbers: true
      margins:
        top: 2.5cm
        bottom: 2.5cm
        left: 1.5cm
        right: 1.5cm
    typography:
      fontSize: 11pt           # 10pt | 11pt | 12pt
      lineSpacing: relaxed     # tight | snug | normal | relaxed | loose
      fontFamily: Linux Libertine O
    advanced:
      showIcons: true
      showUrls: true
```

邊界由 `geometry` 套件處理，而不是原版的負邊界 `\addtolength` 技巧；字型則透過 `\IfFontExistsTF` 備援機制解析，而不是註解/取消註解的輪盤遊戲。

### 章節別名與重新排序

無需碰觸 LaTeX，就能重新命名任何章節標題或調整章節順序——例如，把 Projects 放在 Work 之前，或把「Work」改名為「Experience」：

```yml lineNumbers
layouts:
  - engine: latex
    template: jake
    sections:
      aliases:
        work: Experience
      order:
        - projects
        - work
```

詳情請參閱[章節別名](/zh-tw/docs/layouts/sections/aliases)和[章節重新排序](/zh-tw/docs/layouts/sections/reorder)。

### 現代化的連結、圖示與 PDF 詮釋資料

頁首的聯絡資訊行會有可點擊的 `tel:` 和 `mailto:` 連結、隱藏連結框線的底線 `\href`，以及可選的 FontAwesome 圖示（並自動從 `fontawesome7` 降級到 `fontawesome5`）。產生的 PDF 還帶有完善的詮釋資料——作者、標題，以及從你的技能推導出的關鍵字——這些都是原始模板從未設定的。

### 經過測試、持續維護

Jake 渲染器附帶超過 700 行的單元測試，涵蓋前言、每個章節和每個版面選項，而且它是建構在與我們 moderncv 模板相同的共享 `LatexRenderer` 基礎之上——因此對渲染管線的改進會自動降臨到 Jake's Resume 上。

## 一覽比較

|----------------|----------------------|-----------------------------|
| 撰寫格式       | 原始 LaTeX           | 結構化 YAML                 |

| 特殊字元       | 手動跳脫             | 自動處理                    |
| 日期           | 手工輸入的字串       | 結構化、在地化              |
| 語言           | 僅英文               | 12 種區域語言，CJK 就緒     |
| 富文字         | 內嵌 LaTeX 巨集      | Markdown 摘要               |
| 模板           | 一個檔案、一種設計   | 一行即可切換                |
| 輸出格式       | 僅 PDF               | PDF、HTML、Markdown         |
| 版面自訂       | 編輯前言             | 設定選項                    |

## 立即試用

```console
$ npm install -g yamlresume
$ yamlresume new resume.yml
# edit resume.yml, set `template: jake`
$ yamlresume build resume.yml
```

或者開啟 [playground](/zh-tw/playground)，將模板切換為 `jake`，直接在瀏覽器中查看效果。
