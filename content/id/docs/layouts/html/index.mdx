---
title: Mesin HTML
---

Mesin HTML menghasilkan versi resume HTML yang bersih dan siap untuk web. Ini
sangat berguna untuk menyematkan resume Anda di situs web, membagikannya secara
online, atau membuat portfolio berbasis web.

## Konfigurasi

Untuk menggunakan mesin HTML, tentukan `engine: html` dalam konfigurasi tata
letak Anda.

```yaml
layouts:
  - engine: html
    template: calm
    # ... opsi lainnya
```

## Bagian

Opsi `sections` memungkinkan Anda menyesuaikan judul bagian dan urutannya. Untuk
informasi lebih lanjut, lihat [dokumentasi bagian](./sections).

```yml lineNumbers
layouts:
  - engine: html
    sections:
      aliases:
        work: "Pengalaman Profesional"
        education: "Pendidikan"
        skills: "Keterampilan"
      order:
        - basics
        - work
        - education
```

## Template

Opsi `template` memungkinkan Anda memilih dari berbagai template. Setiap template
memiliki desain dan tata letak yang unik. Anda dapat menemukan daftar template
yang tersedia di [dokumentasi template](./html/templates).

```yml lineNumbers
layouts:
  - engine: html
    template: calm
```

## Tipografi

Opsi `typography` memungkinkan Anda menyesuaikan gaya font yang digunakan dalam
resume Anda.

### Ukuran Font

Opsi `fontSize` memungkinkan Anda mengatur ukuran font dasar untuk dokumen.
Mesin HTML mendukung ukuran font dari `14px` hingga `20px`.

### Keluarga Font

Opsi `fontFamily` memungkinkan Anda menentukan daftar prioritas nama keluarga
font dan/atau nama keluarga generik. Ini bekerja persis seperti properti CSS
`font-family`.

### Spasi Baris

Opsi `lineSpacing` memungkinkan Anda menyesuaikan spasi baris (leading) dokumen.
YAMLResume menggunakan nilai semantik yang dipetakan ke implementasi spesifik mesin:

| Nilai    | Deskripsi                                   |
| -------- | ------------------------------------------ |
| `tight`  | Spasi kompak untuk muat lebih banyak konten |
| `snug`   | Sedikit lebih banyak ruang dari tight      |
| `normal` | Keseimbangan keterbacaan (default)         |
| `relaxed`| Lebih banyak ruang antar baris            |
| `loose`  | Tata letak sangat ruang                   |

```yaml
layouts:
  - engine: html
    typography:
      fontSize: 16px
      fontFamily: "Merriweather, serif"
      lineSpacing: relaxed
```

## Tema

Opsi `theme` memungkinkan Anda menyesuaikan tampilan visual resume Anda
tanpa memengaruhi geometri tata letak yang terukur (ukuran halaman, margin,
ukuran font) atau struktur bagian. Saat ini mendukung warna aksen, dan semua
template HTML menghormatinya.

```yml lineNumbers
layouts:
  - engine: html
    theme:
      colors:
        accent: burgundy # atau warna hex arbitrer seperti "#1B365D"
```

Preset warna aksen mengikuti palet skema warna
[moderncv](https://github.com/moderncv/moderncv). Jika warna aksen tidak
diatur, setiap template kembali ke palet bawaannya.

## Lanjutan

Opsi `advanced` memungkinkan Anda mengonfigurasi pengaturan lanjutan untuk mesin
HTML.

### Menampilkan Anchor

Opsi `showAnchors` mengontrol apakah akan mengeluarkan atribut `id` fragmen
pada bagian dan entri untuk navigasi anchor. Opsi ini aktif secara default:
dengan anchor aktif, setiap bagian mendapatkan id seperti `work` dan setiap
entri mendapatkan id seperti `work-2`, sehingga Anda dapat menautkan langsung
ke bagian tertentu dari resume.

```yml lineNumbers
layouts:
  - engine: html
    advanced:
      # Mengeluarkan atribut `id` fragmen pada bagian dan entri.
      showAnchors: true
      showIcons: true
      # Judul kustom untuk dokumen HTML.
      title: "Judul Resume Kustom Saya"
      # Footer kustom untuk dokumen HTML.
      footer: "Dihasilkan oleh <a href=\"https://yamlresume.dev\">YAMLResume</a>"
      # Meta description untuk dokumen HTML.
      description: "Deskripsi singkat resume untuk SEO."
      # Meta keywords untuk dokumen HTML.
      keywords: "resume, cv, yamlresume"
```
