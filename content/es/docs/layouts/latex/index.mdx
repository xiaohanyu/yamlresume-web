---
title: Motor LaTeX
---

El motor LaTeX es el motor central de YAMLResume, diseñado para producir currículums en PDF de alta calidad y aspecto profesional utilizando plantillas LaTeX.

## Configuración

Para usar el motor LaTeX, especifique `engine: latex` en su configuración de diseño.

```yaml
layouts:
  - engine: latex
    template: moderncv-banking
    # ... otras opciones
```

## Página

La opción `page` le permite personalizar la configuración de la página, como el
tamaño del papel, los márgenes y si mostrar los números de página.

```yml lineNumbers
layouts:
  - engine: latex
    page:
      showPageNumbers: true
      # a4 o letter
      paperSize: a4
      margins:
        top: 2.5cm
        left: 1.5cm
        right: 1.5cm
        bottom: 2.5cm
```

## Secciones

La opción `sections` le permite personalizar los títulos de las secciones y su orden. Para obtener más información, consulte la [documentación de secciones](./sections).

```yml lineNumbers
layouts:
  - engine: latex
    sections:
      aliases:
        work: "Experiencia Profesional"
        education: "Educación"
        skills: "Habilidades"
      order:
        - basics
        - work
        - education
```

## Plantillas

La opción `template` le permite elegir entre una variedad de plantillas. Cada plantilla tiene un diseño y una disposición únicos. Puede encontrar una lista de plantillas disponibles en la [documentación de plantillas](./latex/templates).

```yml lineNumbers
layouts:
  - engine: latex
    template: moderncv-banking
```

## Tipografía

La opción `typography` le permite personalizar los estilos de fuente utilizados en su currículum.

### Tamaño de fuente

La opción `fontSize` le permite establecer el tamaño de fuente base para el documento.
El motor LaTeX solo admite `10pt`, `11pt` y `12pt`.

### Familia de fuentes

La opción `fontFamily` le permite especificar una lista priorizada de nombres de familias
de fuentes. Esto funciona de manera similar a la propiedad CSS `font-family`.

### Espaciado de línea

La opción `lineSpacing` le permite ajustar el espaciado de línea (interlineado) del documento.
YAMLResume usa valores semánticos que se mapean al comando `\setstretch{}` de LaTeX:

| Valor    | Descripción                                    |
| -------- | -------------------------------------------- |
| `tight`  | Espaciado compacto para caber más contenido  |
| `snug`   | Un poco más de espacio que tight            |
| `normal` | Legibilidad equilibrada (predeterminado)    |
| `relaxed`| Más espacio entre líneas                    |
| `loose`  | Diseño muy espacioso                        |

```yaml
layouts:
  - engine: latex
    typography:
      fontSize: 11pt
      fontFamily: "Merriweather, serif"
      lineSpacing: relaxed
```

## Tema

La opción `theme` le permite personalizar la apariencia visual de su
currículum sin afectar la geometría de diseño medible (tamaño de página,
márgenes, tamaños de fuente) ni la estructura de secciones. Actualmente
admite colores de acento. El motor markdown ignora la opción theme.

```yml lineNumbers
layouts:
  - engine: latex
    theme:
      colors:
        accent: burgundy # o un color hexadecimal arbitrario como "#1B365D"
```

Para la salida LaTeX, las plantillas moderncv asignan el color de acento al
`color1` de moderncv, mientras que la plantilla jake define un
`accentcolor` personalizado para los títulos de sección y filetes. Cuando no
se establece un color de acento, cada plantilla conserva su paleta
predeterminada.

## Avanzado

La opción `advanced` le permite configurar ajustes avanzados para el motor
LaTeX.

```yml lineNumbers
layouts:
  - engine: latex
    advanced:
      showIcons: true
      fontspec:
        numbers: Lining
```
