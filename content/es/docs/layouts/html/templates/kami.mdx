## Implementación

Kami (紙, "paper") es una plantilla HTML cálida e inspirada en la impresión: un
fondo de pergamino, una sola voz serif y acentos discretos en color tinta,
compuesta como un informe bien tipografiado. Es una buena opción para
candidatos que buscan un estilo clásico y literario en una página web.

Internamente, la plantilla utiliza:

- **Paleta Cálida**: Un fondo de pergamino con acentos en color tinta para
  titulares, títulos de sección, enlaces y etiquetas de habilidades
- **Una Sola Voz Serif**: Una pila serif basada en Charter mantiene toda la
  página en una sola familia tipográfica, con etiquetas en versalitas para
  fechas y categorías
- **Soporte de Color de Acento**: Respeta `theme.colors.accent` en toda la página
- **Diseño Responsivo**: Se adapta limpiamente de pantallas de escritorio a
  móviles
- **HTML Semántico**: Estructura HTML5 adecuada para mejor accesibilidad y SEO

## Configuración

```yml lineNumbers title="resume.yml"
content:
  # ...

layouts:
  - engine: html
    template: kami    # [!code highlight]
    typography:
      fontSize: 16px
```

## Características

- **Diseño Inspirado en la Impresión**: Parece un documento cuidadosamente
  tipografiado, tanto en pantalla como en papel
- **Color de Acento Personalizable**: Tiñe titulares, títulos de sección,
  enlaces y etiquetas de habilidades mediante `theme.colors.accent`
- **Listo para Web**: Puede incrustarse directamente en sitios web o
  compartirse mediante URL
- **Apto para Impresión**: Optimizado para imprimir a PDF desde navegadores web
- **Secciones Personalizables**: Orden y nomenclatura flexible de secciones
