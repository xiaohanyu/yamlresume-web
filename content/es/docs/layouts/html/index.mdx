---
title: Motor HTML
---

El motor HTML genera versiones HTML limpias y listas para la web de su
currículum. Esto es particularmente útil para incrustar su currículum en sitios
web, compartirlo en línea o crear un portafolio basado en la web.

## Configuración

Para usar el motor HTML, especifique `engine: html` en su configuración de
diseño.

```yaml
layouts:
  - engine: html
    template: calm
    # ... otras opciones
```

## Secciones

La opción `sections` le permite personalizar los títulos de las secciones y su
orden. Para obtener más información, consulte la [documentación de
secciones](./sections).

```yml lineNumbers
layouts:
  - engine: html
    sections:
      aliases:
        work: "Experiencia Profesional"
        education: "Educación"
        skills: "Habilidades"
      order:
        - basics
        - work
        - education
```

## Plantillas

La opción `template` le permite elegir entre una variedad de plantillas. Cada
plantilla tiene un diseño y una disposición únicos. Puede encontrar una lista de
plantillas disponibles en la [documentación de plantillas](./html/templates).

```yml lineNumbers
layouts:
  - engine: html
    template: calm
```

## Tipografía

La opción `typography` le permite personalizar los estilos de fuente utilizados
en su currículum.

### Tamaño de fuente

La opción `fontSize` le permite establecer el tamaño de fuente base para el documento.
El motor HTML admite tamaños de fuente desde `14px` hasta `20px`.

### Familia de fuentes

La opción `fontFamily` le permite especificar una lista priorizada de nombres de familias
de fuentes y/o nombres genéricos de familias. Esto funciona exactamente como la
propiedad CSS `font-family`.

### Espaciado de línea

La opción `lineSpacing` le permite ajustar el espaciado de línea (interlineado) del documento.
YAMLResume usa valores semánticos que se mapean a implementaciones específicas del motor:

| Valor    | Descripción                                    |
| -------- | -------------------------------------------- |
| `tight`  | Espaciado compacto para caber más contenido  |
| `snug`   | Un poco más de espacio que tight            |
| `normal` | Legibilidad equilibrada (predeterminado)    |
| `relaxed`| Más espacio entre líneas                    |
| `loose`  | Diseño muy espacioso                        |

```yaml
layouts:
  - engine: html
    typography:
      fontSize: 16px
      fontFamily: "Merriweather, serif"
      lineSpacing: relaxed
```

## Tema

La opción `theme` le permite personalizar la apariencia visual de su
currículum sin afectar la geometría de diseño medible (tamaño de página,
márgenes, tamaños de fuente) ni la estructura de secciones. Actualmente
admite colores de acento, y todas las plantillas HTML los respetan.

## Avanzado

La opción `advanced` le permite configurar ajustes avanzados para el motor HTML.

### Mostrar Anclas

La opción `showAnchors` controla si se emiten atributos `id` de fragmento en
las secciones y entradas para la navegación por anclas. Está habilitada de
forma predeterminada: con las anclas activadas, cada sección obtiene un id
como `work` y cada entrada obtiene un id como `work-2`, por lo que puede
enlazar directamente a una parte específica del currículum.

```yml lineNumbers
layouts:
  - engine: html
    advanced:
      # Emite atributos `id` de fragmento en secciones y entradas.
      showAnchors: true
      showIcons: true
      # Título personalizado para el documento HTML.
      title: "Mi Título de Currículum Personalizado"
      # Pie de página personalizado para el documento HTML.
      footer: "Generado por <a href=\"https://yamlresume.dev\">YAMLResume</a>"
      # Meta descripción para el documento HTML.
      description: "Una breve descripción del currículum para SEO."
      # Meta palabras clave para el documento HTML.
      keywords: "currículum, cv, yamlresume"
```
