---
title: LaTeX エンジン
---

LaTeX エンジンは YAMLResume のコアエンジンであり、LaTeX テンプレートを使用して高品質でプロフェッショナルな外観の PDF 履歴書を作成するように設計されています。

## 設定

LaTeX エンジンを使用するには、レイアウト設定で `engine: latex` を指定してください。

```yaml
layouts:
  - engine: latex
    template: moderncv-banking
    # ... その他のオプション
```

## ページ

`page` オプションにより、用紙サイズ、マージン、およびページ番号の表示など、ページ設定をカスタマイズできます。

```yml lineNumbers
layouts:
  - engine: latex
    page:
      showPageNumbers: true
      # a4 または letter
      paperSize: a4
      margins:
        top: 2.5cm
        left: 1.5cm
        right: 1.5cm
        bottom: 2.5cm
```

## セクション

`sections` オプションにより、セクションタイトルとその順序をカスタマイズできます。詳細については [セクション文書](./sections) をご覧ください。

```yml lineNumbers
layouts:
  - engine: latex
    sections:
      aliases:
        work: "Professional Experience"
        education: "Education"
        skills: "Skills"
      order:
        - basics
        - work
        - education
```

## テンプレート

`template` オプションにより、様々なテンプレートから選択できます。各テンプレートには独特なデザインとレイアウトがあります。利用可能なテンプレートのリストは [テンプレート文書](./latex/templates) で確認できます。

```yml lineNumbers
layouts:
  - engine: latex
    template: moderncv-banking
```

## タイポグラフィ

`typography` オプションを使用すると、履歴書で使用されるフォントスタイルをカスタマイズできます。

### フォントサイズ

`fontSize` オプションを使用すると、ドキュメントの基本フォントサイズを設定できます。
LaTeX エンジンは `10pt`、`11pt`、`12pt` のみをサポートしています。

### フォントファミリー

`fontFamily` オプションを使用すると、フォントファミリー名の優先順位付きリストを指定できます。
これは CSS の `font-family` プロパティと同様に機能します。

### 行間

`lineSpacing` オプションを使用すると、ドキュメントの行間を調整できます。
YAMLResume はセマンティック値を使用し、LaTeX の `\setstretch{}` コマンドにマッピングされます：

| 値        | 説明                                   |
| --------- | ------------------------------------ |
| `tight`   | より多くのコンテンツを収めるためのコンパクトな間隔 |
| `snug`    | tight よりわずかに多いスペース           |
| `normal`  | バランス 取れた読みやすさ（デフォルト）    |
| `relaxed` | 行間に更多のスペース                   |
| `loose`   | 非常にゆったりとしたレイアウト            |

```yaml
layouts:
  - engine: latex
    typography:
      fontSize: 11pt
      fontFamily: "Merriweather, serif"
      lineSpacing: relaxed
```

## テーマ

`theme` オプションを使用すると、測定可能なレイアウトジオメトリ（ページサイズ、余白、
フォントサイズ）やセクション構造に影響を与えることなく、履歴書の視覚的な外観を
カスタマイズできます。現在はアクセントカラーをサポートしています。markdown
エンジンは theme オプションを無視します。

### アクセントカラー

`theme.colors.accent` オプションは、セクションタイトル、罫線、リンク、
その他のハイライトされた要素に使用されるアクセントカラーを設定します。名前付きカラープリセットの
いずれか、または任意の `#RRGGBB` 形式の16進カラーコード文字列を受け付けます：

| <span style={{display:'inline-block',width:'.9rem',height:'.9rem',borderRadius:'.2rem',border:'1px solid rgba(128,128,128,.5)',backgroundColor:'#0081A7'}} />    | `cerulean` | `#0081A7` |

```yml lineNumbers
layouts:
  - engine: latex
    theme:
      colors:
        accent: burgundy # または "#1B365D" のような任意の16進カラー
```

LaTeX 出力では、moderncv テンプレートはアクセントカラーを moderncv の
`color1` にマッピングし、jake テンプレートはセクションタイトルと罫線のためにカスタムの
`accentcolor` を定義します。アクセントカラーが設定されていない場合、各テンプレートは
デフォルトのパレットを保持します。

## 高度な設定

`advanced` オプションにより、LaTeX エンジンの高度な設定を行うことができます。

```yml lineNumbers
layouts:
  - engine: latex
    advanced:
      showIcons: true
      fontspec:
        numbers: Lining
```
