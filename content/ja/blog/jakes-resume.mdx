[Jake's Resume](https://github.com/jakegut/resume) は、史上最も人気のある LaTeX 履歴書テンプレートのひとつです。Jake Gutierrez が [sb2nov's resume](https://github.com/sb2nov/resume) をベースに作成したこのテンプレートは、GitHub で 2,800 以上のスターを獲得し、クリーンで 1 カラム、ATS フレンドリーなデザインによって履歴書コミュニティでの定番の推奨テンプレートとなっています。

YAMLResume は [v0.12](/ja/blog/v0.12) で Jake's Resume を公式 LaTeX テンプレートとして採用しました。この記事では、YAMLResume 上で Jake's Resume がどのように見えるか、そして——より重要なことに——オリジナルのテンプレートに対して YAMLResume が何を改善したかを紹介します。

## オリジナルの Jake's Resume

オリジナルのテンプレートは、1 つの `resume.tex` ファイルです。コンテンツを 1 語書く前に、パッケージ、余白調整のハック、セクションの書式設定、そして `\resumeSubheading`、`\resumeItem`、`\resumeProjectHeading` といった一連のカスタムマクロを含む約 100 行のプリアンブルを読み進めることになります。

コンテンツは LaTeX で直接記述します。

```latex
\section{Education}
  \resumeSubHeadingListStart
    \resumeSubheading
      {Southwestern University}{Georgetown, TX}
      {Bachelor of Arts in Computer Science, Minor in Business}{Aug. 2018 -- May 2021}
  \resumeSubHeadingListEnd
```

![オリジナルの Jake's Resume](/static/images/blog/jakes-resume/original-jakes-resume.png)

出来上がりは美しいのですが、執筆体験は純粋な LaTeX です。すべての日付範囲を手入力し、すべての特殊文字をエスケープし（`Texas A\&M University`）、LaTeX の悪名高い不可解なエラーログを読みながら括弧の不一致をデバッグします。別のフォントに変えたい？`\usepackage` の行をコメントアウトしたり戻したりします。第二言語がほしい？ファイルを書き直すしかありません。

興味のある方のために、218 行の `resume.tex` ソース全文を掲載します。

## 残したもの

Jake's Resume を Jake's Resume たらしめているデザインの DNA は、意図的にそのまま残しました。実際、テンプレートを YAMLResume のアーキテクチャに適合させた結果、オリジナルのプリアンブルから生き残ったのは 2 つのパーツだけです。

```latex
% Sections formatting
\titleformat{\section}{
  \vspace{-4pt}\scshape\raggedright\large
}{}{0em}{}[\color{black}\titlerule \vspace{-5pt}]

% Custom commands
\newcommand{\resumeSubheading}[4]{
  \begin{tabular*}{\textwidth}[t]{l@{\extracolsep{\fill}}r}
    \textbf{#1} & #2 \\
    \textit{#3} & \textit{#4} \\
  \end{tabular*}
}
```

- `\titleformat` — 水平罫線付きのスモールキャップのセクション見出し
- `\resumeSubheading` — 日付を右揃えにした 2 行のエントリーヘッダー。職歴、学歴、プロジェクト、その他すべての日付付きセクションで使用されます

中央揃えのヘッダー、` $|$ ` の連絡先セパレーター、コンパクトな `nosep` の箇条書きリストと合わせて、これらがテンプレートの視覚的アイデンティティ全体を担っています。それ以外のもの——約 12 のパッケージと 1 ページ分のマクロ——はすべて、YAMLResume の共通レンダリングパイプラインに置き換えられました。

## 改善したもの

見た目を維持するのは簡単な部分でした。本当の価値は、YAMLResume がその周囲に追加するすべてのものにあります。

### コンテンツとプレゼンテーションの分離

オリジナルのテンプレートでは、履歴書そのもの*が* LaTeX コードです。YAMLResume では、履歴書はデータです。テンプレートの切り替えは 1 行の変更で済みます。

```yml lineNumbers
layouts:
  - engine: latex
    template: jake                  # or moderncv-banking, moderncv-casual, ...
```

また `layouts` はリストなので、1 つの YAML ファイルから Jake's Resume の PDF、Web 向けの [HTML ページ](/ja/docs/layouts/html)、プレーンテキストの応募フォーム用の [Markdown](/ja/docs/layouts/markdown) コピーまで、すべて 1 回の `yamlresume build` で生成できます。

### スキーマ検証付きの構造化データ

すべてのフィールドは公開された [JSON Schema](/ja/docs/compiler/schema) で定義されています。ファイル先頭の `yaml-language-server` ディレクティブにより、エディターが入力補完、インラインドキュメント、リアルタイムの検証を提供します。学位、言語の流暢さ、スキルレベル、プロフィールのネットワークは列挙型です——タイポは 40 行に及ぶ LaTeX のエラーログの後ではなく、コンパイル前に検出されます。

### 手動エスケープはもう不要

オリジナルのテンプレートでは `Texas A\&M University` と書く必要がありました。YAMLResume では `Texas A&M University` と書くだけです——LaTeX のエスケープはレンダリング時に、あらゆる場所で一貫して自動的に適用されます。

### 構造化されたローカライズ済みの日付

日付はマクロに埋め込まれた文字列ではなく、データ（`startDate: Aug 2018`）です。YAMLResume はドキュメント全体で一貫した書式に整え、空の `endDate` は「Present」としてレンダリングされます——履歴書の言語に翻訳された形で。

### 本物の国際化

オリジナルのテンプレートは英語に固定されています。YAMLResume は [12 のロケール言語](/ja/docs/locale)——英語、中国語（簡体字、繁体字香港、繁体字台湾）、スペイン語、フランス語、ノルウェー語、オランダ語、日本語、ドイツ語、インドネシア語、ブラジルポルトガル語——をサポートしています。セクションタイトル、学位、流暢さレベル、日付フォーマットは自動的に翻訳され、言語ごとの `babel` 設定と、`ctex` および Noto フォントによる適切な CJK 組版が行われます。

### Markdown サマリー

すべての `summary` フィールドは、実用的な markdown のサブセット——**太字**、*斜体*、リスト、[リンク](https://yamlresume.dev)——を受け付け、正しい LaTeX に変換されます。オリジナルのテンプレートでは `\textbf{}` や `itemize` 環境をインラインで手書きしていました。

### タイポグラフィとレイアウトの制御

オリジナルではプリアンブルの編集が必要だったことが、ここでは設定オプションになっています。

```yml lineNumbers
layouts:
  - engine: latex
    template: jake
    page:
      paperSize: a4            # a4 | letter
      showPageNumbers: true
      margins:
        top: 2.5cm
        bottom: 2.5cm
        left: 1.5cm
        right: 1.5cm
    typography:
      fontSize: 11pt           # 10pt | 11pt | 12pt
      lineSpacing: relaxed     # tight | snug | normal | relaxed | loose
      fontFamily: Linux Libertine O
    advanced:
      showIcons: true
      showUrls: true
```

余白はオリジナルの負のマージンによる `\addtolength` ハックではなく `geometry` パッケージで処理され、フォントはコメントアウトの切り替えではなく `\IfFontExistsTF` によるフォールバックで解決されます。

### セクションのエイリアスと並べ替え

LaTeX に触れることなく、セクションタイトルの変更やセクションの並べ替えができます——たとえば Projects を Work の前に置いたり、「Work」を「Experience」に改名したり。

```yml lineNumbers
layouts:
  - engine: latex
    template: jake
    sections:
      aliases:
        work: Experience
      order:
        - projects
        - work
```

詳しくは[セクションのエイリアス](/ja/docs/layouts/sections/aliases)と[セクションの並べ替え](/ja/docs/layouts/sections/reorder)をご覧ください。

### モダンなリンク、アイコン、PDF メタデータ

ヘッダーの連絡先行には、クリック可能な `tel:` および `mailto:` リンク、リンク枠を隠した下線付きの `\href`、オプションの FontAwesome アイコン（`fontawesome7` → `fontawesome5` への自動フォールバック付き）が付きます。生成される PDF には適切なメタデータ——著者、タイトル、スキルから導出されたキーワード——も含まれます。オリジナルのテンプレートにはこれらが一切設定されていません。

### テスト済みでメンテナンスされている

Jake レンダラーには、プリアンブル、すべてのセクション、すべてのレイアウトオプションをカバーする 700 行を超えるユニットテストが付属しており、moderncv テンプレートと同じ共通の `LatexRenderer` ベースの上に構築されています——そのため、パイプラインへの改善は自動的に Jake's Resume にも反映されます。

## 一目でわかる比較

|                        | オリジナルの Jake's Resume | YAMLResume `template: jake`        |
|------------------------|----------------------------|------------------------------------|
| 執筆フォーマット       | 生の LaTeX                 | 構造化 YAML                        |
| 検証                   | LaTeX のコンパイルエラー   | JSON Schema + IDE の入力補完       |
| 特殊文字               | 手動エスケープ             | 自動                               |
| 日付                   | 手入力の文字列             | 構造化・ローカライズ済み           |
| 言語                   | 英語のみ                   | 12 のロケール言語、CJK 対応        |
| リッチテキスト         | インラインの LaTeX マクロ  | Markdown サマリー                  |
| テンプレート           | 1 ファイル = 1 デザイン    | 切り替えは 1 行                    |
| 出力フォーマット       | PDF のみ                   | PDF、HTML、Markdown                |
| レイアウトのカスタマイズ | プリアンブルを編集         | 設定オプション                     |
| セクション名の変更・並べ替え | マクロを書き直す       | 設定オプション                     |

## 今すぐ試す

```console
$ npm install -g yamlresume
$ yamlresume new resume.yml
# edit resume.yml, set `template: jake`
$ yamlresume build resume.yml
```

あるいは[プレイグラウンド](/ja/playground)を開いてテンプレートを `jake` に切り替えれば、ブラウザー上で実際の動作を確認できます。
